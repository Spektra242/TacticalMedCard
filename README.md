## 📌 Descripción General

**TacticalMedCard** es una plataforma integral diseñada para la creación, personalización y producción de credenciales médicas de emergencia de alta resistencia física e información clínica estandarizada para operaciones en entornos hostiles.

La aplicación permite generar tarjetas médicas en formato estándar internacional **CR-80** (dimensiones de tarjeta de crédito/bancaria), listas para impresión térmica directa en tarjetas plásticas de PVC (300 y 600 DPI), hojas de plegado y laminado en papel A4, e interacción digital de campo mediante códigos **QR vCard offline** y **grabación física de chips NFC** en parches tácticos de rescate.

### 🎯 Público Objetivo
- **Equipos de Búsqueda y Rescate (SAR)**: Rescate en montaña, agreste, marítimo y operaciones aeromédicas.
- **Operadores Tácticos y Fuerzas de Seguridad**: Protocolos de trauma en combate (TCCC / TECC / Casualty Cards).
- **Deportistas Outdoor & Expediciones**: Montañistas, ultraciclistas, escaladores y expedicionarios remotos.
- **Trabajadores en Faenas Críticas**: Operadores de minería en altura, cuadrillas forestales y brigadas de rescate industrial.
- **Primeros Respondientes & Paramédicos (EMS)**: Médicos de trauma, bomberos y rescatistas de emergencias.

## 🚀 Funcionalidades Principales

### 1. 🩸 Gestión Clínica y Triage de Campo
- **Grupo Sanguíneo y Factor Rh Destacado**:
  - Selector dual con formato estándar **ABO (A+, O-, B+, AB+)** y compatibilidad con el sistema numérico **Jansky / Romano (A II +, O I -, B III +, etc.)**.
- **Alertas Críticas de Red Flags**:
  - Detección visual rápida de alergias severas (Shock Anafiláctico, Penicilina, AINEs) y patologías preexistentes (Asma, Diabetes, Hipertensión).
- **Ubicación de Medicación en Equipo / Mochila**:
  - Señalización precisa de dónde encontrar el botiquín, EpiPen, inhalador o torniquete en el uniforme o IFAK si el operador se encuentra inconsciente.
- **Directivas Médicas Anticipadas**:
  - Indicadores claros de donante de órganos y directivas de transfusión sanguínea.
- **Protocolo de Comunicaciones de Emergencia**:
  - Frecuencias de radio SAR directas (VHF / PMR) y soporte completo para matriz **PACE** (Primary, Alternate, Contingency, Emergency).
- **Reverso Alternativo TCCC M.I.S.T.**:
  - Formato estandarizado de reporte de bajas en combate DD-1380 (*Mechanism, Injury, Symptoms, Treatment*).

### 3. 💳 Exportación para Tarjetas Plásticas PVC (CR-80)
Módulo específico para imprentas térmicas directas a tarjeta plástica (*Zebra, Evolis, Magicard, Fargo, Datacard*):
- **Estándar ISO/IEC 7810 ID-1**: Medidas exactas de **85.60 × 53.98 mm (3.370" × 2.125")**.
- **Resolución Técnica**:
  - **300 DPI Estándar**: **1011 × 638 px** (nitidez perfecta sin aberraciones).
  - **600 DPI Alta Definición**: **2022 × 1276 px** (para retransferencia térmica).
- **Selector de Sangrado (Bleed)**:
  - *Sin Sangrado*: Borde a borde exacto para tarjetas sueltas.
  - *Con Sangrado (+2mm perimetral)*: Para planchas troqueladas en imprentas industriales.
- **Renderizado Fuera de Pantalla**: Tanto el frente como el dorso se clonan a un sandbox DOM independiente para asegurar su posición vertical recta (sin la rotación a 180° del modo folleto).
- **Descargas Disponibles**: Descarga individual de *Frente*, *Dorso* o el *Kit Completo*.

### 4. 📡 Tecnología de Campo: Grabación y Lectura de Chips NFC
Permite transferir la ficha clínica del operador directamente a chips físicos NFC incrustados en parches de velcro militar, pulseras o tarjetas inteligentes:
- **Compatibilidad con Chips NTAG**:
  - **NTAG213 (144 bytes / ≤140B útiles)**: Formato compacto especial para parches textiles.
  - **NTAG215 (504 bytes)**: Formato extendido con historial médico completo.
  - **NTAG216 (888 bytes)**: Capacidad máxima.
- **Medidor Dinámico de Memoria**: Calcula en tiempo real el peso en bytes de la ficha médica e ilumina una barra de progreso indicando la compatibilidad del chip antes de escribir.
- **4 Formatos de Transmisión NDEF**:
  1. ⚡ **Ficha Compacta Rescate**: Sintaxis de alta densidad (`[ICE] NOMBRE | ID | SANGRE | ALERG | ICE`).
  2. 📋 **Ficha Médica Completa**: Resumen exhaustivo de condiciones, alergias y contactos.
  3. 📇 **Contacto vCard ICE**: Estándar vCard 3.0 reconocido por cualquier smartphone para guardar el contacto de emergencia automáticamente al aproximar el chip.
  4. 🌐 **Enlace Web / Satelital**: URL a ficha en la nube o baliza GPS.
- **Radar Táctico HUD**: Animación de escaneo circular de 360° durante la búsqueda del tag.
- **Soporte Nativo en Android**: Uso de `NfcAdapter.enableReaderMode` con confirmación háptica (vibración en terreno).
- **Soporte Web NFC**: En Google Chrome para Android mediante la Web NFC API (`NDEFReader`).

### 5. 📄 Hoja de Impresión A4 Dúplex & Mini-Parches
Para quienes no cuentan con impresora PVC rígida:
- **Alineación Perfecta con Guías de Corte (Crop Marks)**: Tarjeta frontal y trasera alineadas para corte exacto con guillotina.
- **Plegado a 180° Invertido**: El dorso se imprime rotado a 180° para que, al doblar por el centro, queden ambas caras perfectamente orientadas y listas para plastificar o termolaminar.
- **2 Mini-Parches Tácticos**: Cada hoja A4 incluye en la base dos mini-credenciales tipo parche de 50 × 30 mm para portar en el reloj, correa de mochila, casco o IFAK.

## 💻 Plataformas Soportadas

TacticalMedCard cuenta con versiones totalmente operativas para cada entorno:

### 1. 🖥️ Windows Desktop (Nativo)
- Aplicación de escritorio desarrollada sobre **Electron**.
- Diálogos nativos de guardado de archivos PNG y JSON.
- Impresión directa con diálogo de Windows (`Ctrl + P`).
- **Ubicación ejecutable**: `TacticalMedCard.exe`

### 2. 📱 Android (APK Nativo)
- Aplicación móvil con interfaz táctica adaptativa.
- Hardware NFC nativo (lectura y grabación directa de parches con retroalimentación háptica).
- Guardado de credenciales directamente en la galería de fotos (`MediaStore`).
- **Paquete de instalación**: `TacticalMedCard.apk`

### 3. 🌐 Web Standalone (Página Web Autónomo)
- Empaquetado como un **único archivo HTML (Single-File HTML)** sin dependencias de servidor ni CDN.
- Contiene todo el código CSS, librerías gráficas (`html2canvas`, `qrcode.js`) y assets en Base64.
- Listo para subir a **GitHub Pages**, **Vercel**, **Netlify**, o embeber en cualquier sitio web vía `<iframe>`.
- **Archivo principal**: `index.html` (dentro de la carpeta `TacticalMedCard-Web`).

## 🛠️ Instalación & Despliegue

### Despliegue en GitHub Pages (Gratis en 1 Minuto)
1. Crea un repositorio público en tu cuenta de GitHub (ej. `tactical-medcard`).
2. Sube el archivo `index.html` de la carpeta `TacticalMedCard-Web` a la raíz del repositorio.
3. Ve a **Settings > Pages** en el repositorio.
4. En **Branch**, selecciona `main` (carpeta `/root`) y presiona **Save**.
5. Tu aplicación estará en vivo en:  
   `https://<tu-usuario>.github.io/tactical-medcard/`
